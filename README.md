# PennyPilot

## 项目定位

PennyPilot 是一个面向个人日常消费的桌面记账工具。用户可以通过表单手动记账，也可以用自然语言描述消费内容。系统使用 AI 识别消费信息并生成消费诊断，同时由程序完成金额校验、数据统计和图表生成，兼顾记账效率与结果可靠性。

## 功能清单

- **手动记账**：填写金额、分类、日期和备注，新增收入或支出记录。
- **自然语言记账**：输入消费描述，由 AI 提取金额、分类和日期，并在用户确认后保存。
- **账目管理**：浏览、筛选、编辑和删除历史账目。
- **预算设置**：设置月度分类预算，查看预算余额和超支情况。
- **统计分析**：通过分类占比、消费趋势和预算执行图表展示消费情况。
- **消费诊断**：由程序汇总统计数据，再由 AI 生成易于理解的消费分析与建议。
